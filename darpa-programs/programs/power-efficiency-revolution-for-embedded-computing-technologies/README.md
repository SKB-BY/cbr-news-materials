## Назначение (цитата DARPA)

> The goal of DARPA’s Power Efficiency Revolution For Embedded Computing Technologies (PERFECT) program is to seek revolutionary approaches and to research and develop the technologies and techniques that will provide the power efficiency required to enable embedded computing systems.
