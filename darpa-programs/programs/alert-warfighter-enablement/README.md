> Combining light simulation and photo-pharmaceuticals — a category of drugs that are only active in the presence of certain types of light — to target specific brain circuits, DARPA’s Alert WARfighter Enablement (AWARE) program aims to safely stimulate brain function to improve alertness for a controlled time period.
