## Назначение (цитата DARPA)

> The Neural Evidence Aggregation Tool (NEAT) program aims to overcome current limitations by developing a new cognitive science tool that identifies people at risk of suicide by using preconscious brain signals rather than asking questions and waiting for consciously filtered responses.
