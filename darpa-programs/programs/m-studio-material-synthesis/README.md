## Назначение (цитата DARPA)

> The Material Synthesis Technologies for Universal and Diverse Integration Opportunities (M-STUDIO) program seeks to pioneer a new, universal heterogeneous integration (HI) method for producing advanced semiconductor materials through atomic-precision synthesis of nanoscale, multi-layer structures.
