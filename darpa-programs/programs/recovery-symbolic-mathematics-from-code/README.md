## Назначение (цитата DARPA)

> The Recovery of Symbolic Mathematics from Code (ReMath) Artificial Intelligence Exploration (AIE) program aims to discover whether a combination of recent advances in AI techniques, such as neural machine translation, sequence-to-sequence encoders, etc., can effectively recover mathematical structures implemented in software into their natural mathematical forms of symbolic expression.
