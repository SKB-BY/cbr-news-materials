## Назначение (цитата DARPA)

> The GOLDen hour extended EVACuation (GOLDEVAC) program aims to test whether it is possible to manage a complex polytrauma patient, starting near the point of injury and continuing throughout the evacuation process, via a single intravascular cannula that can be placed by a field medic.
