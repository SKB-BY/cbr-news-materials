## Назначение (цитата DARPA)

> The objective of the EDGE program is to develop the tools necessary to create, measure, and test Human Machine Interfaces (HMI) that provide enough situational awareness (SA) of a system’s processes and status in addition to its operational environment so the operator can adapt the system in off-nominal situations.
