## Назначение (цитата DARPA)

> The Enhanced SBOM for Optimized Software Sustainment (E-BOSS) program aims to develop the capability to preempt or rapidly triage and remediate software vulnerabilities at an infrastructure scale through revolutionary changes in software build chains and runtime systems that enhance and complement SBOM technologies.
