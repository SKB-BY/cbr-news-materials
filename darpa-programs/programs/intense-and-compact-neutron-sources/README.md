## Назначение (цитата DARPA)

> The Intense and Compact Neutron Sources (ICONS) program seeks to achieve highly portable, intense neutron sources to enable deployable, high-resolution neutron and x-ray imaging for DoD applications such as non-destructive evaluation, detection of explosives and special nuclear materials, and forensics.

Источник: [https://www.darpa.mil/research/programs/intense-and-compact-neutron-sources](https://www.darpa.mil/research/programs/intense-and-compact-neutron-sources)
