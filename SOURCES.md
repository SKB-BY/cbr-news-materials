# Источники сбора

Перечень источников живой базы, без объёмов. Карточка: тип (RSS / HTML / Telegram / API / реестр); что даёт по ВПК; ограничения; резервный канал; периодичность проверки (7 или 30 дней); метод сбора. Проверено с сервера сбора 13.11.2026, дополнения поиска источников 14.11.2026 и 15.11.2026, Europe/Minsk.

Российские предприятия и холдинги, если указаны ниже, используются только как **новостные источники**. В карту реестра и в реестр сил и компаний российские юрлица не включаются.

Экономические и финансовые ленты (Банк России, Интерфакс, ПРАЙМ, Ведомости, РБК, Коммерсантъ, Smart-Lab) **не подключены как постоянные RSS**, хотя их ленты 13.11.2026 открывались. Их можно использовать только точечно — по названиям предприятий ОПК (финансы, ГОЗ, санкции, суды, кадры, производство, экспорт/импорт).

## Наши официальные ресурсы РБ (подключены 16.11.2026, t140u/t141u)

Группа «наши официальные ресурсы РБ»: органы власти, госСМИ, посольства и Госкомвоенпром (ГВПК) с организациями его системы. Telegram — только публичное превью `t.me/s`. Проверка — 16.11.2026 с сервера cbr-srv-big.

Правила:

- **Фильтр «Контура»** (как у экономических лент, t115u). В отчёт, карты и сводку попадает только то, что совпало с темой БПЛА, со сферами «Контура», с организациями реестра или с темой внешнего давления на РБ (санкции, провокации, нарушения границы, информационные атаки, НАТО и т.п.).
- **Все записи группы** за окно сбора хранятся отдельно на сервере (таблица `rb_official_raw`). В публикации они не идут. Индекс информационного давления (ИИД) не утверждён и не реализован.
- **Ступень ОИ по типу источника**, пока истории мало:
  - **А** — официальный сайт или канал, на который ссылается официальный сайт;
  - **Б** — госСМИ;
  - **В** — канал без ссылки с официального сайта, в основании ОИ: «принадлежность не подтверждена официальным сайтом».
- **Язык:** русский и белорусский. Перевод be→ru — Helsinki-NLP `opus-mt-tc-big-zle-zle` (локально, CTranslate2), правило t134u.

## Сбор браузером с бокса (t146u, 16.11.2026; правила обновлены 16.11.2026 — t149s777, t150u)

Источники, которые не отдают страницы сборщику сервера (HTTP 403, сетевой отказ), собираются с бокса — отдельной машины проекта с другим сетевым выходом. Доступ честный: защиту не обходим.

- **Кто запрашивает.** Настоящий браузер Chrome без окна (Playwright) с честной подписью: `HeadlessChrome/<версия>` и метка `KONTUR-I-OSINT-BY/1.0 (+ссылка на эту страницу; public news monitoring; low-rate)`. Для лент RSS и простых страниц браузер не запускается: запрос идёт с той же меткой.
- **Подмены User-Agent нет нигде.** Решение GREEN 16.11.2026 («Убрать подмену»): у сборщика сервера удалён повтор запроса с обычной подписью браузера Chrome после HTTP 403 (t76u, `fetchutil.py`). Сервер и бокс подписываются только своей меткой. Ответ 403 сервер записывает в `logs/http403.jsonl`.
- **robots.txt — рекомендация, а не запрет** (решение GREEN t150u, 16.11.2026). На боксе robots.txt читается до первой страницы, `Crawl-delay` соблюдается как темп (militarnyi.com — 100 с). Запрет `Disallow`, `Content-Signal: search=no` или недоступный robots.txt сбор не останавливают. Такой случай пишется в журнал `fetch.jsonl` как `robots_ignored`. Сборщик сервера правила robots.txt по-прежнему соблюдает.
- **Страница проверки.** Капча, Cloudflare «Один момент…», «Access Denied», WAF, HTTP 401/403/429/503 — «источник заблокирован». Капчи и проверки не проходим. После блокировки источник не запрашивается 24 ч, потом одна попытка.
- **Частота.** Не чаще 1 прохода на цикл: за 15–40 мин до старта цикла сервера. На источник — 1 листинг и не больше 4 статей (vpk.gov.by — 6). Пауза между запросами к одному сайту — не меньше 10 с.
- **Чего нет.** Учётных записей, чужих cookies, прокси, ротации адресов и подмены отпечатка. Выходной узел VPS не используется.
- **Изоляция.** Отдельный системный пользователь `cbrbrowse` без входа в систему. Песочница bwrap: нет домашних каталогов, рабочих файлов, ключей SSH и паролей. Есть только сеть, сам браузер, код только для чтения и свой каталог профиля. Загрузки файлов и service workers запрещены; картинки, видео и шрифты не загружаются.
- **Выход и путь на сервер.** Только текст (JSONL): ссылка, заголовок, дата, текст, язык. Файлы передаёт отдельный шаг с проверкой sha256. На сервере `browser_inbox.py` (флаг `CBR_BROWSER_INBOX=1`) проводит каждый материал обычным путём: классификатор, сфера, контур (окрас, субъективность, дедуп), правило слухов, затем ОИ 5×5 и перевод. Id источника — тот же, что у сервера: группа и буква ОИ не меняются.
- **Перезапуск бокса.** Цикл прохода (`browse-loop.sh`) поднимает сторож опросчика ОИ (`oi-watchdog.sh`, каждые 2 мин), если есть файл `ENABLED`.
