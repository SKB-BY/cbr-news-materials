# Материалы CBR: сбор новостей по БЛА и реестр программ DARPA

Публичный репозиторий документов, таблиц и материалов по проектам ЦБР.
Ссылки открываются без запроса доступа.

Описание репозитория: «Сбор новостей». Тематика: дроны / БЛА / БПЛА / БАК / БАС / БЭК (воздух, земля, вода; военные, промышленные, коммерческие, FPV), обнаружение и противодействие, навигация без GNSS.

## Содержимое

- [Актуальный отчёт](АКТУАЛЬНЫЙ_ОТЧЁТ.md) — проанализированная, выверенная и структурированная информация по живой базе (классификация и правило слухов). В отчёт включены подтверждённые новости; заявления — отдельно, если без них картина темы неполна. Слухи в отчёт не входят. Статистика (количество новостей по категориям, разделам, темам и крупнейшие источники живой базы) в отчёт и в этот файл не включается.
- [Реестр компаний](companies.csv) — 107 записей (ранее 79): агентства, компании и программы. Вид `program`: Replicator, JCO, European Drone Defence Initiative / European Drone Wall, GCAP; добавлены агентства и компании. Рабочий реестр, не полный перечень всех фирм. Ссылки — официальные сайты; заказчики указаны только при наличии источника.
- [Источники сбора](SOURCES.md) — перечень источников живой базы без объёмов.
- [Программы DARPA](darpa-programs/README.md) — отдельный контур по каждой программе: организации и листинг, инвестиционный статус, персоналии, проверка вводного списка.

## Программы DARPA

Каждая программа лежит в каталоге `darpa-programs/programs/<slug>/`.

- Таблицы: [darpa-programs/data/](darpa-programs/data/)
- Как добавить программу: [ADD_PROGRAM.md](darpa-programs/ADD_PROGRAM.md)
- Проверка вводного списка: [LEAD_CHECK.md](darpa-programs/LEAD_CHECK.md)
- Материалы без отнесения к программе: [UNASSIGNED.md](darpa-programs/UNASSIGNED.md)

Это рабочий реестр, не полный перечень всех программ DARPA.

## Правило слухов

- Слух — одна цепочка без второго независимого источника.
- Заявление — названа организация, но источник один.
- Новость — подтверждена хотя бы одним независимым изданием (не перепечатка).

## Что не публикуется

Живая база и архив (SQLite), токены и служебные ключи в этот репозиторий не входят.

Сбор ведётся только из открытых источников (сайты и публичные страницы t.me/s). Время материалов — Europe/Minsk.
