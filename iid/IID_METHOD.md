# ИИД-100 — методика (КОНТУР - I-OSINT BY)

Версия методики `iid100-1`. Утверждение: GREEN t143u, 16.11.2026: внедрить по образцу; веса и пороги — из образца.

ИИД-100 (Индекс информационного давления) показывает, насколько неблагоприятная повестка складывается в отношении Республики Беларусь в собранных открытых источниках. Шкала 0–100: **100 — максимальное давление**.

**Без ИИ.** Не используются нейросети, языковые модели, обучаемые классификаторы и модели тональности, векторные представления слов, машинный перевод. Только словари ([IID_DICTIONARIES.md](IID_DICTIONARIES.md)), формулы и пороги ([iid_config.json](iid_config.json)). Сопоставление материалов на разных языках — только по общим числам, датам, местам и организациям.

## Какие материалы входят

- Упоминание Беларуси по словарю упоминаний (страна, Президент, органы власти, населённые пункты РБ, организации реестра с пометкой BY) на языках ru, be, uk, pl, lt, lv, en, de.
- Язык — по алфавиту и словарю служебных слов; материал на языке без словарей в ИИД не входит (счётчик «вне расчёта»).
- Источники из Беларуси (в т. ч. группа «наши официальные ресурсы РБ») в индекс давления не входят: их материалы — «наш ответ».
- Нужен код ОИ 5×5 (шлюз «Контура»). Сутки — 00:00–24:00 Europe/Minsk по времени публикации. Страна — страна издателя по карточке источника. Сфера — одна основная сфера по классификатору «Контура».

## Формула

(1) ИИД = округление(100 × (wV·kV + wO·kO + wS·kS + wR·kR + wC·kC)), w = 0.25 + 0.25 + 0.2 + 0.15 + 0.15 = 1,00.

| Составляющая | w | k (0…1) | По материалу |
|---|---|---|---|
| Объём V | 0.25 | kV = min(1; max(0; (N/B − 1)/2)), B = max(1; M30/30) | M30 — материалов за 30 предыдущих суток |
| Окрас O | 0.25 | kO = Σn / N | n = max(0; −S), S — окрас по предложениям с упоминанием РБ |
| Субъективность S | 0.2 | kS = ΣSubj / \|M⁻\| | Subj — правила «Контура» |
| Вес ОИ 5×5 R | 0.15 | kR = Σr / \|M⁻\| | r = a(буква) × b(цифра) |
| Согласованность C | 0.15 | kC = Σc / \|M⁻\| | c = 1, если за 24 ч материалы сюжета дали ≥ 3 семьи |

M⁻ — негативные материалы (S ≤ −0,2). При |M⁻| = 0: kS = kR = kC = 0. Округления: S, Subj — 0,1; r — 0,01; k — 0,001; ИИД — целое; «половина вверх». ИИД считается из округлённых k, поэтому **индекс = сумма вкладов составляющих** (проверяется при каждом расчёте и в export_check).

**Окрас.** S = (2·сп + п − 2·сн − н)/(сумма весов + 2); без сильных признаков не дальше ±0,5; −1…+1. **Субъективность.** 0,1 + 0,15 за оценочное слово (≤ 4) + 0,1 за «!!» в тексте или «!!!» в заголовке + 0,15 за первое лицо + 0,05 за «??» + 0,1 за 2+ слова из 5+ заглавных в заголовке; ≤ 1.

**Ячейки** страна × сфера — формула (1) по материалам ячейки; N < 3 — «—». Итоги по стране, сфере и суткам — по объединённым суммам. **Вклад** ячейки или сюжета = ИИД × |M⁻ за сутки| / |M⁻ суток|. **ИИД за 7 дней** — среднее 7 суточных значений.

## Сюжеты давления и наш ответ

- Два материала — один сюжет, если между ними ≤ 72 ч и: один язык — шинглы из 4 слов (после приведения к основе) по Жаккару ≥ 0.35 или косинус TF-IDF ≥ 0.6, и ≥ 1 общий ключ; разные языки — ≥ 3 общих ключа, из них ≥ 1 число или дата. Сюжет — связная группа. IDF — по корпусу 30 суток до начала суток.
- Ключи: числа (единая запись; без малых чисел < 10 и годов 1990–2035), даты (дд.мм.гггг), места (код топонима), организации и лица (код словаря или реестра).
- Сюжет давления — сюжет с ≥ 1 негативным материалом.
- Ответ — первый материал группы «наши официальные ресурсы РБ» (rb_official.py, t140u; также сырой учёт rb_official_raw) с ≥ 2 ключами сюжета в 72 ч от начала t0. Задержка ≤ 12 ч — своевременный.
- Качество Q = (r + (1 − Subj) + f)/3, f = min(1; ключей/3); ≥ 0.7 высокое, ≥ 0.5 среднее. Если у ответа нет кода ОИ 5×5 — буква по типу источника, цифра 3 (сведения не проверены), с пометкой.
- ИИД сюжета — формула (1), kV = min(1; v/10), v — материалов в сутки. Окно «до» = [max(t0; tr − 72 ч); tr), «после» = [tr; tr + 72 ч); без ответа tr = t0 + 72 ч. Δ ≤ −5 — снижение, Δ ≥ +5 — усиление; пока окно «после» не закрыто, эффект не ставится.
- Цитирования — материалы сюжета в окне «после», где назван ресурс ответа и есть ключ ответа.

**Эффективность ответов — корреляция, не доказательство причины.** На повестку влияют и другие события тех же дней; вывод о пользе ответа делается по многим сюжетам.

## Воспроизводимость

- Одинаковый вход → одинаковый результат; порядок обработки — время публикации, затем id; случайных чисел и обучаемых параметров нет.
- Каждый расчёт выполняется дважды на одном снимке; расхождение — значение не публикуется (код выхода 2).
- С каждым значением хранятся версия методики, хэш снимка входа и промежуточные суммы (N, M30, Σn, |M⁻|, ΣSubj, Σr, Σc): таблицы `iid_daily`, `iid_cell`, `iid_story`, `iid_run` и файл `iid.json`.
- Самопроверки: индекс = Σ вкладов, нет NaN, k в 0…1, зоны, Σ ячеек = итог суток, ИИД 7 дней = среднее ряда.

## Зоны

0–25 спокойно · 26–50 умеренно · 51–75 высокое · 76–100 критическое.

## Ограничение текущего сбора

Сбор «Контура» ориентирован на БПЛА, ВПК и сферы «Контура»; общеполитические ленты зарубежных СМИ в него не входят. Поэтому ИИД-100 сейчас отражает давление в этом срезе источников.
