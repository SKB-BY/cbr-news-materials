ИИД-100 — Индекс информационного давления

Насколько неблагоприятная повестка складывается в отношении Республики Беларусь в собранных открытых источниках. Шкала 0–100: 100 — максимальное давление. Расчёт без нейросетей, языковых моделей и машинного перевода: словари, формулы и пороги (раздел «Методика»). Сутки — 00:00–24:00 Europe/Minsk.

—

1. Текущие значения

0–25 спокойно26–50 умеренно51–75 высокое76–100 критическое

2. Составляющие (расчётные сутки)

ИИД = округление(100 × (wV·kV + wO·kO + wS·kS + wR·kR + wC·kC)). Сумма вкладов равна индексу.

3. Страны источников × сферы

Ячейка — ИИД по формуле (1) только по материалам этой страны и сферы; ячейка с N < 3 — «—» (выборка мала, но материалы входят в итоги). Итоги — по объединённым суммам, не среднее ячеек. Запись «ИИД · N/|M⁻|».

Нажмите ячейку — список негативных материалов этой страны и сферы за расчётные сутки (из сюжетов давления).

4. ИИД за 30 дней и наши ответы

Линия — ИИД за сутки, столбцы — N (материалов о Беларуси). ▲ зелёная — время ответа наших ресурсов; ✕ красная — окончание окна ответа (72 ч) у сюжета без ответа.

5. Сюжеты давления и наш ответ

Сюжет давления — связная группа материалов (72 ч; один язык — шинглы/TF-IDF и общий ключ; разные языки — ≥ 3 общих ключа, из них ≥ 1 число или дата), в которой есть негативный материал (окрас ≤ −0,2). Ответ — первый материал группы «наши официальные ресурсы РБ» с ≥ 2 ключами сюжета в 72 ч от начала.

6. Эффективность ответов

Корреляция, не доказательство причины. Это совпадение по времени: на повестку влияют и другие события тех же дней; вывод о пользе ответа делается по многим сюжетам, а не по одному.

7. Методика

  • Какие материалы входят. Материал входит в ИИД, если в нём найдено упоминание Беларуси по словарю упоминаний (страна, Президент, органы власти, населённые пункты РБ, организации реестра с пометкой BY) на языках ru, be, uk, pl, lt, lv, en, de — поиск по основе слова с фиксированным списком окончаний языка и по границе слова. Язык — по алфавиту и словарю служебных слов. Материалы на других языках и материалы источников из Беларуси в расчёт не входят (счётчик «вне расчёта»).
  • Страна — страна издателя по карточке источника; редакции, работающие на аудиторию РБ из-за рубежа, — отдельная категория «Белорусские СМИ за рубежом» со своим весом; сфера — одна основная сфера материала (БПЛА, затем ПВО/РВСН, авиация, вооружение, бронетехника, артиллерия, связь, ПО, джипы, тактика), остальные — теги; тот же порядок — в Актуальном отчёте и на Новостной карте.
  • Окрас S — только по предложениям, где названа Беларусь: S = (2·сп + п − 2·сн − н)/(Σвесов + 2); без сильных признаков не дальше ±0,5; −1…+1, до 0,1. Негативный материал — S ≤ −0,2.
  • Субъективность — 0,1 + 0,15 за оценочное слово (не более 4) + 0,1 за «!!» + 0,15 за первое лицо + 0,05 за «??» + 0,1 за 2+ слова ЗАГЛАВНЫМИ в заголовке; до 0,1, не выше 1.
  • Вес источника r = a(буква) × b(цифра) × охват × категория: А 1,0 … Д 0,2; 1 = 1,0 … 5 = 0,2; охват и категория — плашка весов в разделе 2 (iid_config.json).
  • Согласованность c = 1, если за 24 ч до материала (включая его) материалы того же сюжета дали ≥ 3 разные издательские семьи.
  • Составляющие: kV = min(1; max(0; (N/B − 1)/2)), B = max(1; M30/30); kO = Σn/N, n = max(0; −S); kS = ΣSubj/|M⁻|; kR = Σr/|M⁻|; kC = Σc/|M⁻|; при |M⁻| = 0 kS = kR = kC = 0.
  • ИИД сюжета — та же формула по материалам окна; kV = min(1; v/10), v — материалов в сутки. Окно «до» = [max(t0; tr − 72 ч); tr), «после» = [tr; tr + 72 ч); без ответа tr = t0 + 72 ч. Δ ≤ −5 — снижение, Δ ≥ +5 — усиление; пока окно «после» не закрыто, эффект не ставится.
  • Качество ответа Q = (r + (1 − Subj) + f)/3, f = min(1; общих ключей/3): ≥ 0,70 высокое, ≥ 0,50 среднее. Своевременный — не позже 12 ч.
  • Вклад ячейки или сюжета = ИИД × |M⁻ ячейки (сюжета) за сутки| / |M⁻ суток|.
  • Округления: S, Subj — 0,1; r — 0,01; k — 0,001; ИИД — целое; везде «половина вверх».

Словари признаков, упоминаний, топонимов и организаций, карточки стран источников и все коэффициенты — в каталоге iid/ репозитория (IID_METHOD.md, IID_DICTIONARIES.md, iid_config.json, iid_lex.json, iid_sources.json).

8. Воспроизводимость

  • Одинаковый вход → одинаковый результат. Случайных чисел и обучаемых параметров нет; порядок обработки — время публикации, затем идентификатор.
  • Каждый расчёт выполняется дважды на одном снимке входа; при расхождении значение не публикуется.
  • С каждым значением хранятся версия методики, хэш снимка и промежуточные суммы (N, M30, Σn, |M⁻|, ΣSubj, Σr, Σc) — пересчёт возможен на калькуляторе (таблица суточного ряда ниже).
  • Не используются: нейросети, языковые модели, обучаемые классификаторы и модели тональности, векторные представления слов, машинный перевод.
